# Critic: Provocateur (Shklovsky), round R2

- **Anchor used:** Shklovsky, *Art as Technique*. The device makes the stone stony by making perception slow. A device fails if the eye never reaches it.
- **Observed:** index_html-desk.png has "VIEW: Built / Bare" on the frame's own bar, beside "THEME EVERY PART", above the fold. In index-bare-desk.png all 18 pieces become orange-tagged skeletons in place, inside a frame that stays built. On the phone (index-bare-phone.png) the switch sits in the frame and 7 pieces are bared. A gloss reads "Bare: no styles; every element and every slot… labelled." index-slab-desk.png sets the same 18 objects in a monospaced slab, a third reading. "Sprue" survives only as a class name (index.html lines 39, 40, 103).
- **Findings:**
  - F1 [claim] My R1 request is answered. X-ray is one press away on the first screen and bares the whole kit at once.
  - F2 [claim] A built frame holding bare parts makes "pricing table" visible as conventions, made.
  - F3 [defect] (minor) At miniature scale the Bare tags can't be read and show as orange hatching. The estrangement registers as texture, not as words. Part pages carry the full X-ray.
  - F4 [premise] The numbered "doors" list is habit, but it is a route list and does not claim to be new. I accept it, and I accept dropping "sprue" from the text.
- **Verdict:** PASS
- **Requested change:** F1, F2, F4: none. F3 (optional): in Bare, on hover or focus, enlarge one piece's tags so they can be read.
