# R1 · Critic: Erasure (Kelly Walters)

**Anchor used:** Black, Brown + Latinx Design Educators (Kelly Walters): a resource teaches only when a student without insider context can enter it and sees more than one kind of student in it.

**Observed:**
- Each part page lists Slots, Needs and Access. Fields have visible labels, and "(required)" is written in text. The check gives 18/18 on labels, focus and contrast. Every page sets `lang`.
- CONTRIBUTING now matches the code: the parts need nothing, and the site needs Node and Playwright.
- The templates are set in Lagos, in Mexico City (in Spanish, with translated aria-labels), in Fremantle, and for a fictional app.
- The step-by-step paste guide ("Put the tokens' :root block in the head") appears only on agents.html. Humans get the landing doors: bare verbs on a phone ("Pick / Assemble / Start / Fetch") and jargon on desktop ("Pick parts from the sprue").
- The parts' default copy is one garden business, Harbor & Pine. The site interface is English only. No document names a learner.

**R0 status:** F1, F2 and F3 resolved. F4 partly resolved. F5 open.

**Findings:**
- F1 [defect] The agent is taught step by step and the human beginner is not. "head", "token" and "sprue" go unexplained.
- F2 [defect] The phone doors are verbs without objects, so a newcomer cannot tell where "Fetch" or "Assemble" leads.
- F3 [claim] The part defaults teach one kind of client. The variety sits in the templates, one click deeper.
- F4 [premise] There is still no named first-time learner, and no test with one.

**Verdict:** OBJECT (narrow)

**Requested change:**
- F1: add a human "Paste your first part" page and link it from the landing.
- F2: give the doors full labels at every width.
- F3: vary the part defaults across the template contexts.
- F4: name a learner persona in DESIGN-LOG and record one walkthrough with that person.
